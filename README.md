# Sleep Disorder Classification Using Artificial Neural Networks (ANN)

## 📚 Published IEEE Research Paper

**Research Paper Title:** *A Novel Approach for Classification of Sleep Disorder Using a Machine Learning Algorithm*

**Publication/Conference:** IEEE 4th International Conference on Advanced Technologies (ICONAT 2025)

**Research Area:** Machine Learning | Artificial Neural Networks | Healthcare

This project is associated with my IEEE research paper on machine learning-based sleep disorder classification, presented at IEEE 4th ICONAT 2025.

## 📌 Project Overview

Sleep disorders can significantly affect an individual's physical health, mental well-being, and overall quality of life. This project presents a machine learning-based approach to classify sleep disorders using health, lifestyle, and sleep-related attributes.

An Artificial Neural Network (ANN) is used to classify individuals into three categories: **Normal (No Sleep Disorder), Sleep Apnea, and Insomnia**.

The model achieved a reported classification accuracy of **96%** on the evaluated dataset.

## 🎯 Objectives

- Develop an ANN-based model for sleep disorder classification.
- Analyze the relationship between sleep patterns, health indicators, and lifestyle factors.
- Preprocess and scale input features to improve model training.
- Classify sleep-related data into three categories.
- Explore the application of machine learning in sleep health analysis.

## ✨ Key Features

- **Three-Class Classification:** Predicts Normal, Sleep Apnea, or Insomnia.
- **Data Preprocessing:** Prepares input data for model training.
- **Artificial Neural Network:** Uses a multilayer neural network for classification.
- **Feature Scaling:** Applies StandardScaler to standardize numerical features.
- **Performance Evaluation:** Reports the model's classification accuracy.
- **Healthcare Research:** Explores machine learning applications in sleep health analysis.
